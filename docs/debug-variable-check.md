# デバッグで変数の変化を確認

実施日：2026/10/11
対象：Main.xaml

## 確認方法

attemptCountを加算する代入にブレークポイントを設定。
ファイルをデバッグし、ローカルパネルで値を確認した。

## 確認結果

| 停止位置 | 代入前 | ステップオーバー後 |
|---|---:|---:|
| 1回目の入力後 | 0 | 1 |
| 2回目の入力後 | 1 | 2 |

## 学んだこと

- ブレークポイントは対象の処理を実行する直前で停止する。
- ステップオーバーで対象の処理を進められる。
- ループでは同じブレークポイントに繰り返し到達する。
- 無効なブレークポイントは位置を残して停止を解除できる。

確認後、実行を終了し、ブレークポイントを無効にした。
