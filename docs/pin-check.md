# 暗証番号の確認ロボット

作成日：2026/10/12
ワークフロー：PinCheck.xaml
設計図：docs/PinCheck.drawio

## 仕様
- 正しい暗証番号は文字列の "0427"。
- 入力は最大3回。
- 正解なら「認証成功」と表示して終了する。
- 不正解なら「暗証番号が違います」と表示する。
- 3回とも不正解なら「入力回数の上限に達しました」と表示する。
- 空欄も不正解として1回に数える。
- 3回目の正解も成功にする。

## 実行方法
StudioでPinCheck.xamlを開き、「ファイルを実行」を選ぶ。

## テスト結果
| 入力順 | 期待結果 | 実結果 |
|---|---|---|
| 0427 | 成功して終了 | 未記入 |
| 1234 → 0427 | 不正解 → 成功 | 未記入 |
| 1234 → 1111 → 0427 | 3回目に成功、上限表示なし | 未記入 |
| 1234 → 1111 → 9999 | 不正解3回 → 上限表示、4回目の入力なし | 未記入 |
| 空欄 → 空欄 → 空欄 | 不正解3回 → 上限表示 | 未記入 |
| 427 → 0427 | 不正解 → 成功 | 未記入 |

## 学んだこと
- 暗証番号は先頭の0を保持するためStringで扱う。
- Ifは処理を分岐し、Whileは繰り返しを続けるか判断する。
- 成功メッセージを表示するだけではループは終了しない。
- 回数上限と不正解の条件をAndAlsoで組み合わせる。

## 修正したこと
- 代入の右側を attemptCount + 1 に修正した。
- 空欄判定を、暗証番号の不一致判定へ変更した。
- Whileの条件に、暗証番号が不正解であることを追加した。
