# 変数のスコープ

実施日：2026/10/13
対象：ScopePractice.xaml

## 学んだこと
変数は、設定したスコープとその内側から参照できる。
二つの子シーケンスで共有する場合は、共通の親に定義する。

## 実習結果
| スコープ | 確認内容 | 結果 |
|---|---|---|
| 入力処理 | 入力処理内でuserNameを表示 | 昭人と表示された |
| 入力処理 | 隣の表示処理からuserNameを参照 | 想定どおりエラーになった |
| ScopePractice | 両方の子シーケンスから表示 | 昭人が2回表示された |

## 最終構成
- 親のScopePracticeにString型のuserNameを定義。
- 入力処理で「昭人」を代入して表示。
- 表示処理でも同じuserNameを表示。
