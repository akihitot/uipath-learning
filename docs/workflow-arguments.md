# ワークフローの引数：In・Out・In/Out

実施日：2026/10/12

## 学んだこと
方向は、呼び出されるワークフローから見たもの。

| 方向 | 役割 |
|---|---|
| In | 値を受け取る |
| Out | 結果を返す |
| In/Out | 値を受け取り、更新して返す |

代入を使うことと、引数の方向がIn/Outであることは別。
InとOutを分けて、入力から別の結果を作ることもできる。

## 実習1：挨拶文の作成
- 呼び出し元：GreetingPractice.xaml
- 呼び出し先：CreateGreeting.xaml
- userNameをIn引数のin_Nameへ渡す。
- Out引数のout_GreetingをgreetingMessageで受け取る。
- 呼び出し先では挨拶文を作り、呼び出し元で表示する。

## 実習2：回数の更新
- 呼び出し元：CountPractice.xaml
- 呼び出し先：IncrementCount.xaml
- countの初期値は0。
- In/Out引数のio_Countへcountを対応付ける。
- 呼び出すたびに1増やして返す。
- 表示にはcount.ToString()を使い、数値を文字列に変換する。
