# 制作する自動化ロボットの候補10個

資格学習期間は実習A/Bを優先します。他のテーマは合格後の発展候補です。各作品は目的・入力・出力・正常/異常系・再実行・起動手順をREADMEに残します。

| 番号 | テーマ | 今回の扱い | 最小の成果物と検証 |
|---|---|---|---|
| 1 | ファイル整理・命名 | 発展候補 | 拡張子で分類、実行前の確認、同名・0件・再実行を検証 |
| 2 | Excel整形・集計 | 実習A | 必須列・欠損・数値・重複を検証し、整形表と期待値を保存 |
| 3 | CSV差分・突合 | 発展候補 | 主キーで追加・変更・削除を抽出し、並び順変更と重複キーを検証 |
| 4 | ExcelからWeb受注登録 | 実習B | ローカルフォームへ登録し、待機・途中停止・二重登録防止を確認 |
| 5 | API取得と業務レポート | 発展候補 | API／モックJSONを整形し、通信失敗・不正JSON・0件を確認 |
| 6 | メール添付の仕分けと台帳 | 実習Aの部分演習 | ダミーEMLを処理し、添付なし・同名・重複を確認 |
| 7 | フォーム自動回帰テスト | 発展候補 | 正常・異常入力を期待値と比較し、失敗証跡を保存 |
| 8 | Web情報の定時取得・変化検知 | 発展候補 | 練習ページの差分を保存し、未更新・取得失敗・構造変更を検知 |
| 9 | PDF請求書の台帳化 | 実習Aの部分演習 | 架空PDFから番号・日付・金額を抽出し、欠損と重複を検証 |
| 10 | キューによる一括処理・再試行 | 発展候補 | 失敗行だけ再処理し、再開と重複防止を検証 |

検証結果の説明と処理の分割を重視し、将来のJava・C#等での開発にもつながる入出力・状態・例外の考え方を学びます。
